# Contribuer à ActuPub

ActuPub est un protocole ouvert. Les contributions à la spécification sont les bienvenues de la part de tous — que vous soyez développeur, blogueur, journaliste, ou simplement quelqu’un qui se soucie d’un meilleur écosystème d’information.

## Quels types de contributions sont utiles en ce moment

- **Retours sur la spécification** : sections peu claires, cas particuliers manquants, incohérences
- **Expertise technique** : authentification, protocoles de fédération, écosystème JSON Feed
- **Cas d’usage réels** : scénarios que la spécification ne gère pas bien actuellement
- **Traductions** : la spécification est actuellement en français ; une version anglaise aiderait à son adoption

## Comment contribuer

**1. Ouvrez d’abord une Discussion.**
Avant de rédiger une pull request, ouvrez une [Discussion GitHub](../../discussions) pour décrire le problème ou l’idée. Cela permet de garder le débat visible et d’éviter les efforts inutiles.

**2. Ouvrez une Issue pour les bugs clairs dans la spécification.**
Si vous avez trouvé quelque chose qui est clairement erroné ou manquant (un exemple cassé, une affirmation contradictoire, un terme non défini), ouvrez directement une Issue.

**3. Soumettez une Pull Request une fois qu’il y a consensus.**
Les PR qui modifient la spécification doivent faire référence à la Discussion ou à l’Issue qui les a motivées. Gardez les changements ciblés — un sujet par PR.

## Règles de base

- Soyez précis. Les suggestions vagues sont difficiles à exploiter.
- Soyez bienveillant. Il s’agit d’un projet collaboratif, pas d’un club de débat.
- En cas de doute, demandez. Aucune question n’est trop basique.

## Contact

Si vous souhaitez vous impliquer plus profondément — aider à façonner le protocole, travailler sur CuraFed (l’implémentation de référence), ou toute autre chose — contactez-nous directement avant de vous lancer. Voir l’avis en haut du README.
